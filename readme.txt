== Description ==

OctoSqueeze is a powerful image optimization plugin that automatically compresses your images and converts them to modern formats like WebP and AVIF.

= Key Features =

* **Automatic Compression** - Images are compressed automatically when uploaded
* **WebP Conversion** - Generate WebP versions for 30% smaller files
* **AVIF Conversion** - Generate AVIF versions for 50% smaller files
* **Bulk Optimization** - Compress your entire media library with one click
* **Smart Compression** - Three modes: Quality, Balanced, and Size
* **Original Backup** - Keep original files for peace of mind
* **Lazy Loading** - Native lazy loading for faster page loads
* **CDN Ready** - Works with any CDN or caching plugin

= How It Works =

1. Upload an image to WordPress
2. OctoSqueeze compresses it and generates WebP/AVIF versions
3. Your theme automatically serves the best format for each browser
4. Enjoy faster page loads and better Core Web Vitals

= Compression Modes =

* **Quality Mode** - Minimal compression, maximum quality (40-55% reduction)
* **Balanced Mode** - Perfect balance of size and quality (60-75% reduction)
* **Size Mode** - Maximum compression for smallest files (70-85% reduction)

= Requirements =

* WordPress 6.0 or higher
* PHP 8.0 or higher
* OctoSqueeze API key (free tier available)

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/octosqueeze/` or install through the WordPress plugin screen
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Settings > OctoSqueeze to configure
4. Enter your API key (get one free at octosqueeze.com)
5. Choose your compression settings
6. Start uploading optimized images!

== Frequently Asked Questions ==

= Is OctoSqueeze free? =

OctoSqueeze offers a free tier with 100 images per month. For higher volumes, paid plans start at $9/month.

= Will it compress my existing images? =

Yes! Use the Bulk Optimization feature to compress all images in your media library.

= Does it support WebP and AVIF? =

Yes, OctoSqueeze automatically generates WebP and AVIF versions of your images. Modern browsers will be served the most efficient format.

= Will it slow down my site? =

No. Image compression happens on OctoSqueeze's servers, so there's no impact on your server performance. The resulting smaller images will actually make your site faster.

= Are my images secure? =

Yes. Images are encrypted during transfer and automatically deleted from our servers within 24 hours.

= Does it work with page builders? =

Yes! OctoSqueeze works with Elementor, Divi, Beaver Builder, Gutenberg, and all other page builders.
